# Project InTake static page

This folder is a standalone HTML version of the Project InTake landing page.

## Publish at timsarquis.com/projectintake

Upload the entire `projectintake` folder to the web root of `timsarquis.com`.
The final structure should look like:

```text
/projectintake/
  index.html
  styles.css
  /assets/
```

Keep the folder name and internal structure unchanged. The page uses relative
asset paths and requires no package installation, JavaScript framework, or
build command.

If the portfolio is hosted by a framework, copy this folder into its static or
public directory so that `projectintake/index.html` is served at:

https://timsarquis.com/projectintake/
