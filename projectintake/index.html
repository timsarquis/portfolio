Frequently asked questions

Good questions.
Clear answers.

Everything to know before Project InTake is released.

What does Project InTake do?

Project InTake is a native Premiere Pro plugin that watches folders connected to your project and automatically imports new media. It mirrors your folder structure as Premiere bins, waits for copies to finish, prevents duplicate imports, and remembers each project's setup.

How do I download and install it?

Project InTake is currently in testing and is not yet available for public download. It will be released through Adobe Marketplace. When the packaged release is available:

  1. Quit Adobe Premiere Pro.
  2. Double-click the supplied Project InTake .ccx file.
  3. Follow the Creative Cloud Desktop installation prompt.
  4. Reopen Premiere Pro and choose Window → UXP Plugins → Project InTake.

Developer Mode is not required for a packaged .ccx installation.

Which systems and Premiere Pro versions are supported?

Project InTake is available for macOS and Windows and requires Adobe Premiere Pro version 25.6 or newer.

How do I set it up for the first time?
  1. Open and save the Premiere project you want Project InTake to manage.
  2. Open Window → UXP Plugins → Project InTake.
  3. Add the nearby folders Project InTake discovers, or choose Add External Folder.
  4. Confirm the folders under Watched Folders and select Start Watching.

Adding a folder does not start monitoring until Start Watching is selected.

How does it organize and import media?

Folders and subfolders become matching Premiere bins. When new media appears, Project InTake waits until the copy is complete, checks for duplicates, creates the required bins, imports the media, and records it only after Premiere confirms the import.

How does it prevent duplicate imports?

Project InTake compares normalized full file paths against both the active Premiere project and its persistent ingest history. Files with the same name in different folders remain distinct, while media already in Premiere is skipped.

Does it support image sequences?

Yes. Supported numbered image sequences are grouped and imported as sequences instead of hundreds of individual stills. Project InTake waits for the sequence to stabilize before importing it.

Does it remember folders and handle disconnected drives?

Yes. Each saved Premiere project keeps its own watched folders and monitoring state. If a drive disconnects or a folder becomes unavailable, Project InTake keeps the entry, continues watching available folders, and resumes monitoring when the folder returns.

What happens if media is deleted from Premiere?

Project InTake respects intentional deletions. Rescan New Files imports only media that has never been ingested. To restore a deleted project item, use Re-ingest Missing Media…, select the files you want, and confirm the recovery.

How can I tell if everything is working?

Project Health summarizes watched and unavailable folders, queued files, recent scans and imports, duplicate prevention, and plugin uptime. Its Healthy, Attention, Error, and Idle states provide a quick status check.

What should I do if a file does not import?

Allow time for the copy to finish, check the Live Import Queue, confirm the watched folder is available, and select Rescan New Files. Project Health will show a warning or error when something needs attention.

Does Project InTake upload my media or project data?

No. Project InTake operates locally. It does not upload media or directly modify the Premiere project file. Watched folders, monitoring state, ingest history, and related settings are stored in the plugin's private UXP data.

How do I report a problem?

Open Help → Export Diagnostic Report, save the report, then choose Open Support Email. Attach the report and describe what happened, what you expected, and how to reproduce it. Reports can be sent to projectintakeplugin@gmail.com.
